# Car-rental-System
A console-based Car Rental System built in C++ using Object-Oriented Programming (OOP) and basic data structures. It allows users to add vehicles and customers, rent vehicles, and view rental information through a simple menu-driven interface. Ideal for learning OOP concepts in real-life scenarios.

# 🚗 Car Rental System (C++)

A console-based **Car Rental System** developed in **C++** using **Object-Oriented Programming (OOP)** principles and basic **Data Structures**. This system allows users to add vehicles and customers, rent vehicles, and display rental data.

## 📌 Features

- Add new vehicles to the system
- Register new customers
- Rent available vehicles to customers
- View all customers and rentals
- Simple menu-driven interface

## 🧠 Concepts Used

- **Classes & Objects**
- **Encapsulation**
- **Vectors / Arrays**
- **Dynamic memory management**
- **Menu-based navigation**
- **Basic validation checks**

## 🛠 Technologies

- Language: C++
- IDE: Visual Studio / Code::Blocks / Any C++ IDE
- Platform: Console-based (Cross-platform)
